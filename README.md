The most useless superpower imaginable, written for make.fun's "Worst Superpower" bounty ($2 in USDC).

> I can teleport instantly to the exact spot I was standing five seconds ago, provided I close my eyes and really commit to it.

## Run it

```sh
python3 main.py   # writes the line to /output/entry.txt
```

`main.py` is the whole entry: it writes the single line to `/output/entry.txt` (UTF-8, 125 characters, one line) and leaves the file world-readable.
